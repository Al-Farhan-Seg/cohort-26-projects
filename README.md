# Cohort 26 Projects

This repository stores HTML practice projects created for Coder's Club Cohort 2026–2027.

## Project 01: Personal Gallery

`project-01-personal-gallery` is a simple three-page, HTML-only website that presents a personal gallery of places and interests.

### What the project demonstrates

- Organising a website into folders and using relative file paths
- Creating multiple HTML pages and connecting them with navigation links
- Using semantic HTML elements: `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`
- Displaying local images with meaningful alternative text
- Adding image captions with `<figure>` and `<figcaption>`
- Using headings, paragraphs, lists, text-formatting elements, and external links

### Project structure

```text
project-01-personal-gallery/
├── index.html              # Gallery home page
├── about.html              # Information about the gallery
├── favourites.html         # Favourite places and interests
└── images/
    ├── city.jpg
    ├── forest.jpg
    ├── mountains.jpg
    └── ocean.jpg
```

### Viewing the project

Open `project-01-personal-gallery/index.html` in a web browser. Use the navigation links to visit the About and Favourites pages.

### Technology used

- HTML5 only

No CSS or JavaScript is used in this version of the project.
